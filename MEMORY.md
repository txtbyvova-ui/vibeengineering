## Грабли и ловушки

- **Акцентный цвет задан дважды:** `colors.accent = #FF4F00` в `tailwind.config.js`
  и `--accent: #ff4f00` в `src/index.css`. CSS-переменная нужна там, куда Tailwind не достаёт
  (`-webkit-text-stroke`, `::selection`). При смене цвета править оба места.
- **Alias `@` объявлен дважды:** `vite.config.ts` (рантайм) и `tsconfig.json` (типы).
  Менять синхронно.
- **Вёрстка Team рассчитана ровно на 2 карточки** (`md:first:border-r md:last:pr-0`).
  Третий участник сломает бордеры сетки.
- **Ни одна анимация не уважает `prefers-reduced-motion`** — marquee, gridShift, pulseDot,
  smooth scroll, весь Framer Motion. Системный пробел, зафиксирован в
  [docs/BACKLOG.md](docs/BACKLOG.md).
- **Токен `surface: #1A1A1A` не используется нигде**; класс `.hairline` в `src/index.css`
  мёртв — в разметке применяется Tailwind-токен `border-hairline`.
- **Конвенция «контент в `src/data`» нарушена** в `USP.tsx` (`points`) и `Contact.tsx` (`links`) —
  данные объявлены инлайн в компоненте, вопреки README и остальным секциям.

## Аудит 2026-08-05

- Проведён многолинзовый аудит (a11y / performance / SEO / код / тулинг / дизайн-система)
  с состязательной верификацией каждой находки: **72 находки → 63 подтверждено, 9 опровергнуто**.
  Результат — [docs/BACKLOG.md](docs/BACKLOG.md), там же список опровергнутых, чтобы их
  не «находили» заново.
- **Замер:** маска `RevealText` срезает 3.88 px выносных элементов глифов на h1
  (высота маски 66.23 px против 70.12 px ink-бокса при Clash Display 600 / 72 px / `leading-[0.92]`).
- **Замер:** 0 правил `prefers-reduced-motion` из 191 CSS-правила страницы; активны
  3 бесконечные анимации + smooth scroll + 32 инстанса Framer Motion.
- **Замер:** UA-кольцо фокуса на месте (`outline: auto 1px rgb(229,151,0)`, `:focus-visible`
  матчится) — Tailwind preflight его не сбрасывает. Утверждение «фокус не виден» ЛОЖНО;
  проблема только в отсутствии фирменного стиля и в инверсии под `mix-blend-difference`.
- **Замер:** объявлен 31 `@font-face`, реально загружается 6 в 3 семействах — лишние веса
  в запросе байт не стоят.
- **Замер:** тач-цели меньше минимума WCAG 2.5.8 (24×24): пункты меню 36×16 и 64×16,
  логотип 31×24, почта в футере 335×17.
- **Опровергнуто замером:** переполнения вьюпорта на 320 px НЕТ — ни один элемент не выходит
  за границы, ink-overflow = 0, горизонтального скролла нет. Латентные 47 px в `scrollWidth`
  дают клоны marquee, зажатые своим `overflow-hidden`.
- **SUPERSEDED (было в ранней редакции ARCHITECTURE.md):** «Hero — единственная секция
  на `animate` вместо `whileInView`». Неверно: на `animate` идут только микро-лейбл и абзац,
  а сам h1 состоит из шести `RevealText` и ждёт `whileInView`. Исправлено 2026-08-05.
