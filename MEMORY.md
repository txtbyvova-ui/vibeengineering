## Грабли и ловушки

- **Акцентный цвет задан дважды:** `colors.accent = #FF4F00` в `tailwind.config.js`
  и `--accent: #ff4f00` в `src/index.css`. CSS-переменная нужна там, куда Tailwind не достаёт

  Третий участник сломает бордеры сетки.
- **Ни одна анимация не уважает `prefers-reduced-motion`** — marquee, gridShift, pulseDot,
  smooth scroll, весь Framer Motion. Системный пробел, зафиксирован в

- **Токен `surface: #1A1A1A` не используется нигде**; класс `.hairline` в `src/index.css`
  мёртв — в разметке применяется Tailwind-токен `border-hairline`.
- **Конвенция «контент в `src/data`» нарушена** в `USP.tsx` (`points`) и `Contact.tsx` (`links`) —
  данные объявлены инлайн в компоненте, вопреки README и остальным секциям.

## Крупная находка: брендовые шрифты без кириллицы

- **2026-08-05, замерено.** Clash Display — **0 кодпоинтов** в U+0400–U+04FF (разбор TTF);
  Space Grotesk — сабсета `cyrillic` нет в `css2` вовсе (только latin, latin-ext,
  vietnamese); JetBrains Mono — 98 кириллических кодпоинтов, включая `◆`.
  Проверено и в браузере методом сравнения ширины `"Шрифт, monospace"` против `monospace`.
- **Следствие:** весь русский текст сайта рендерится браузерным фоллбэком `sans-serif`,
  а не выбранной типографикой. Дизайн-система не применяется примерно к 95 % того,
  что читает русскоязычный посетитель, при том что три семейства исправно грузятся
  с двух сторонних CDN. Заведено как [BACKLOG.md §0](docs/BACKLOG.md), решение — за брендом.
- **Побочно:** замер §2 (3.88 px срезаемого выносного элемента) посчитан по метрикам
  фоллбэка — то есть по тому, что реально видит пользователь. Замер остаётся валидным.
- **Правило для нового кода:** если текст русский, Clash Display и Space Grotesk
  на него не подействуют. В OG-карточке это учтено.

## Грабли инструментария (2026-08-05)

- **Скриншоты в панели Browser не работают** в этой сессии: панель не отображается,
  кадры не композитятся. Рабочий обход — headless Chrome через CDP
  (`--remote-debugging-port` + `WebSocket` из Node 24, `Page.captureScreenshot`
  с `captureBeyondViewport`).
- **`whileInView` Framer Motion в headless не срабатывает** — проверено и на `main`,
  это не регрессия. Для снимков финальной вёрстки приходится глушить инлайн-стили
  Framer стилем с `!important` (инлайн он переписывает обратно на следующем кадре rAF).
- **Chrome откладывает `loading="lazy"` при быстрой программной прокрутке.**
  Одного прохода `window.scrollTo` мало: нужно катать страницу, пока у всех
  `document.images` не появится `currentSrc`. `img.complete === true` у картинки
  без выбранного источника — на него нельзя опираться.
