# Правила работы в репозитории `vibeengineering`

Уточняет портфельный канон `D:\Code\platform\canon\AGENTS.md`, **не заменяет его**.
Читается вместе с [MEMORY.md](MEMORY.md) и [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## 1. Что это за репозиторий и чем он отличается от остального портфеля

Единственный **веб-репозиторий** в портфеле: Vite + React 18 + TypeScript + Tailwind.
Ни Tekla, ни .NET, ни RE, ни бинарного патчинга здесь нет.

Поэтому **не применяются** целые разделы канона:

| Раздел канона | Статус здесь |
|---------------|--------------|
| §2 TFM `net48`/`netstandard2.0`/`net8` | неприменимо |
| §3 NuGet, приватный фид, `PackageReference` | неприменимо — зависимости через npm |
| §4 RE, Ghidra, `.bak`, доставка патчей | неприменимо |
| §9 engine ↔ delivery, фасад, DTO | неприменимо — нет движка, статический лендинг |
| §10 Tekla API, x64, мультиверсия | неприменимо |

**Применяются полностью:** §4 в части «сначала RAG, потом чтение», §5 (git и рабочий
процесс), §6 (язык), §7 (правила для агентов), §8 (память).

## 3. Команды

```bash
npm install
```

| Команда | Назначение | Состояние |
|---------|-----------|-----------|
| `npm run dev` | dev-сервер на http://localhost:5173 | рабочая |
| `npm run typecheck` | `tsc --noEmit` | рабочая, проходит чисто |
| `npm run og` | генерация `public/og.png` (Satori + resvg) | рабочая, ~2 с |
| `npm run icons` | генерация `public/apple-touch-icon.png` и `favicon.ico` из `favicon.svg` | рабочая |
| `npm run media` | пережатие `site media/` → `public/media` (ffmpeg) | рабочая, **разовая** — в `build` не подключена |
| `npm run build` | `prebuild` (og + icons) → `tsc --noEmit && vite build` | рабочая, ~6 с |
| `npm run preview` | превью прод-сборки | рабочая |
| `npm run lint` | `eslint .` | **сломана** — eslint не установлен и не сконфигурирован |

**Сборка не зависит от сети.** JetBrains Mono лежит в git
([assets/fonts/](assets/fonts/README.md), OFL 1.1 разрешает редистрибуцию явно)
и читается с диска — он несёт всю кириллицу и `◆` OG-карточки.

Clash Display закоммитить **нельзя**: ITF Free Font License запрещает
«uploading them in a public server», а репозиторий публичный (разбор с цитатой —
в том же README). Поэтому он необязателен: скрипт берёт его по Fontshare API
(штатный путь доставки по той же лицензии) и кладёт в `.cache/og-fonts` вне git,
а **при недоступности CDN не падает** — латинский заголовок набирается
JetBrains Mono, карточка собирается, в лог уходит предупреждение.
Раньше отказ CDN ронял `prebuild` и вместе с ним весь деплой.

## 4. Гейт перед словом «готово»

Канон §5: не заявлять «проверено» без проверки. Минимальный набор для этого репо:

1. `npm run build` — обязательно (включает typecheck). Падения показывать с выводом.
2. **Смоук глазами в браузере** — typecheck ничего не знает про вёрстку, hover-состояния
   и анимации. Проверять минимум на 375 px и на десктопе.
3. Если менялась анимация или стили — проверить размер бандла. Ориентир после
   ленты кейсов (2026-08-06): `303.6 kB` JS / `99.5 kB` gzip, `21.3 kB` CSS / `5.2 kB` gzip,
   `6.7 kB` HTML. Рост объяснять.
4. Если добавлялось медиа — перемерить вес первого экрана. Бюджет владельца — **≤200 kB
   медиа выше сгиба**; фактически там **17 kB** (две обложки ленты кейсов грузятся
   `eager` по требованию постановки, но с `fetchpriority="low"`, чтобы не отбирать
   канал у первого экрана). Всё остальное медиа — лениво.

## 5. Конвенции кода (обязательные)

- **Контент — в `src/data/*.ts`, разметка — в компонентах.** Правка текста не должна
  трогать `.tsx`. С контент-релиза v2 исключений нет: в компонентах не осталось
  ни одной пользовательской строки, включая подписи блоков и реквизиты футера.
- **Медиа: производные — в git, оригиналы — нет.** `public/media` коммитится,
  `site media/` (архив владельца) в `.gitignore`. Новый ассет: положить оригинал
  в архив → прописать в `scripts/optimize-media.mjs` → `npm run media` → описать
  в `src/data/media.ts` (интринсики из вывода скрипта, alt — осмысленный).
  Всё, что выводится из исходника кодом (`og.png`, `apple-touch-icon.png`),
  по-прежнему генерируется, а не коммитится.
- **Импорты только через alias `@/`.** Относительных `../` в `src/` быть не должно.
- Один компонент = одна секция, `export default`, без пропсов.
- Типы — `import type` (`isolatedModules: true`).
- Новые цвета/шрифты/easing — **токенами в `tailwind.config.js`**, не хардкодом в классах.
  Если значение нужно в чистом CSS — добавлять CSS-переменную в `src/index.css` и помнить,
  что источник правды всё равно один; расхождение `--accent` ↔ `colors.accent` — известная ловушка.
- Комментарии — только там, где приём неочевиден. Плотность держать как в окружающем коде (низкая).
- ⚠️ **Комментарии в `index.html` уезжают в прод как есть** — Vite их не вырезает,
  и любой посетитель читает их в исходном коде страницы. Держать короткими
  и техническими; разбор, даты, названия сторонних компаний и внутренние
  рассуждения — в `docs/`, со ссылкой из комментария. Проверено 2026-08-07:
  подробный комментарий про `sameAs` вынес имя посторонней организации
  в прод-разметку.
- UI-текст русский, идентификаторы английские.
- ⚠️ **Кириллица есть только в JetBrains Mono.** У Clash Display и Space Grotesk
  её нет вообще (замерено), поэтому любой русский текст рендерится системным
  `sans-serif`, что бы ни стояло в `font-display`/`font-sans`. Не рассчитывать
  на брендовую типографику для русского текста, пока не закрыт
  [BACKLOG.md §0](docs/BACKLOG.md).

## 6. Границы скоупа — не «чинить» самовольно

Осознанные решения проекта, а не упущения:

- **Нет цен на странице** — вместо прайса блок «Смета до строки за 2 часа»
  (`estimate` в [src/data/process.ts](src/data/process.ts)). Не добавлять прайсинг.
- **Нет формы и бэкенда** — лид уходит в Telegram/почту. Не строить формы без задачи.
- **Мат в финальном оффере снят** по распоряжению владельца (2026-08-05) — теперь
  «Проекты начинаются с одного сообщения.» Не возвращать обратно.
- **Первый экран без картинок** — там типографика, сетка и Canvas-ферма. Медиа
  начинается с секции кейсов и всё лениво.
- **Нет роутера, state-менеджера, светлой темы.** См. ARCHITECTURE §10.

## 7. Git

Канон §5 в силе целиком:

- **Не коммитить в `main` напрямую** — сначала ветка.
- **Не пушить без спроса.** Remote — `github.com/txtbyvova-ui/vibeengineering` (чужой аккаунт-владелец).
- Коммит-месседж с трейлером соавтора Claude.
- Перед коммитом проверить, не залетел ли `package-lock.json`, перенормализованный
  `npm install` (npm любит переставлять флаги `"peer": true` — это шум, откатывать).

## 8. RAG

Инструмент — из хаба: `D:\Code\platform\tooling\rag\rag.cmd` (на PATH как `rag`,
если развёрнут `platform Manager`; на этой машине шима на PATH **нет** — звать полным путём).

```bash
rag index --root .
```

```bash
rag query "marquee infinite scroll" --root . --top-k 5
```

Конфиг — [tools/rag.config.json](tools/rag.config.json) (`maxFileBytes: 90000`, чтобы
`package-lock.json` — 111 КБ — не засорял выдачу, но самый крупный документ репозитория,
`docs/SPEC-hero-truss.md` на 68 КБ, в индекс попадал). Здесь и в MEMORY значилось
`65536` — при таком пороге спека молча выпала бы из индекса; число исправлено 2026-08-06
по факту файла. Индекс `.rag/` самоигнорируется, в git не идёт.
Пересобирать после заметных правок исходников.
