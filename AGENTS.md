## 1. Что это за репозиторий и чем он отличается от остального портфеля

Единственный **веб-репозиторий** в портфеле: Vite + React 18 + TypeScript + Tailwind.
Ни Tekla, ни .NET, ни RE, ни бинарного патчинга здесь нет.

С 2026-08-10 добавлены `three`, `@react-three/fiber` и `leva` — сцена первого
экрана. Единственные тяжёлые зависимости проекта, и они **обязаны оставаться
в ленивом чанке**: см. §5 и [docs/REPORT-hero-wireframe.md](docs/REPORT-hero-wireframe.md).

Поэтому **не применяются** целые разделы канона:

| Раздел канона | Статус здесь |
|---------------|--------------|
| §2 TFM `net48`/`netstandard2.0`/`net8` | неприменимо |
| §3 NuGet, приватный фид, `PackageReference` | неприменимо — зависимости через npm |
| §4 RE, Ghidra, `.bak`, доставка патчей | неприменимо |
| §9 engine ↔ delivery, фасад, DTO | неприменимо — нет движка, статический лендинг |
| §10 Tekla API, x64, мультиверсия | неприменимо |

**Применяются полностью:** §4 в части «сначала RAG, потом чтение», §5 (git и рабочий
процесс), §6 (язык), §7 (правила для агентов), §8 (память).

## 3. Команды

```bash
npm install
```

| Команда | Назначение | Состояние |
|---------|-----------|-----------|
| `npm run dev` | dev-сервер на http://localhost:5173 | рабочая |
| `npm run typecheck` | `tsc --noEmit` | рабочая, проходит чисто |
| `npm run og` | генерация `public/og.png` (Satori + resvg) | рабочая, ~2 с |
| `npm run icons` | генерация `public/apple-touch-icon.png` и `favicon.ico` из `favicon.svg` | рабочая |
| `npm run media` | пережатие `site media/` → `public/media` (ffmpeg) | рабочая, **разовая** — в `build` не подключена |
| `npm run build` | `prebuild` (og + icons) → `tsc --noEmit && vite build` | рабочая, ~6 с |
| `npm run preview` | превью прод-сборки | рабочая |
| `npm run lint` | `eslint .` | **сломана** — eslint не установлен и не сконфигурирован |

**Сборка не зависит от сети.** JetBrains Mono лежит в git
([assets/fonts/](assets/fonts/README.md), OFL 1.1 разрешает редистрибуцию явно)
и читается с диска — он несёт всю кириллицу и `◆` OG-карточки.

Заголовочный M PLUS Rounded 1c для карточки тоже OFL, но полный TTF семейства
весит мегабайты (японский шрифт с иероглифами), поэтому в git его нет: скрипт
берёт с Google Fonts сабсет latin+cyrillic (~103 kB) в `.cache/og-fonts` вне git,
а **при недоступности CDN не падает** — заголовок набирается JetBrains Mono,
карточка собирается, в лог уходит предупреждение. Раньше отказ CDN ронял
`prebuild` и вместе с ним весь деплой.

**Шрифты самого сайта сети не требуют вовсе** — они в `public/fonts`, сторонних
CDN и `preconnect` в `index.html` больше нет.

## 4. Гейт перед словом «готово»

Канон §5: не заявлять «проверено» без проверки. Минимальный набор для этого репо:

1. `npm run build` — обязательно (включает typecheck). Падения показывать с выводом.
2. **Смоук глазами в браузере** — typecheck ничего не знает про вёрстку, hover-состояния
   и анимации. Проверять минимум на 375 px и на десктопе.
   ⚠️ **Для CLS двух ширин мало.** Заголовок, чья строка близка по ширине к контейнеру,
   перекидывается туда-обратно при подгрузке шрифта и роняет CLS — но только на тех
   ширинах, где он у границы переноса. Замеренный случай: 0.001 на 375 и 1440 px
   при **0.16 на 1024 px**. Мерить по сетке 320 / 360 / 375 / 768 / 1024 / 1440.
3. Если менялась анимация или стили — проверить размер бандла. Ориентир
   после мержа wireframe-сцены (2026-08-10):

   | | печатает vite | gzip |
   |---|---|---|
   | главный чанк `index-*.js` | 302.15 kB | 99.08 kB |
   | **ленивый `WireframeHeroCanvas-*.js`** | 1037.27 kB | **294.53 kB** |
   | └ из них three + fiber + сцена | 827.71 kB | 223.99 kB |
   | └ из них **leva** | 209.56 kB | **70.54 kB** |
   | CSS | 25.93 kB | 5.97 kB |
   | HTML | — | 2.1 kB |
   | шрифты `public/fonts` (8 woff2) | — | 120 kB |

   ⚠️ **Столбцы расходятся не случайно.** Vite печатает длину чанка в UTF-16
   единицах, а не в байтах: кириллица в UTF-8 занимает два байта, а в длине
   строки считается за одну. Для этого репозитория, где почти весь текст русский,
   **вывод `npm run build` занижает реальный вес** — здесь на 5.3 kB. Для
   сравнения прогонов вывод vite годится, для бюджета — нет; настоящий вес брать
   `wc -c` по файлу или из сетевой панели.

   Рост объяснять. **Рост главного чанка на сотни килобайт = `three` уехал
   не туда**, первый подозреваемый — статический импорт из чего-нибудь,
   что тянется с первого экрана.

4. **Вес первого экрана мерить отдельно на десктопе и на мобиле.**
   Замер с пустым кэшем 2026-08-10, transferred:

   | | всего | из них сцена |
   |---|---|---|
   | мобила 375 | **529.9 kB** | 287.6 kB |
   | планшет 768–1023 | **242.3 kB** | 0 — сцена там не монтируется (2026-08-12) |
   | десктоп 1440 | **539.5 kB** | 287.6 kB |

   Ленивый чанк приезжает **после** `load` и в гонке за LCP не участвует
   (медиана 4 холодных загрузок: старт чанка 950 мс при LCP 848 мс).

   ⚠️ **Действующая сцена грузит `three` и на мобиле** — у wireframe нет
   векторного фолбэка. Это стоило мобильному первому экрану роста
   243.5 → 529.9 kB и остаётся открытым вопросом к владельцу, а не решённым:
   [REPORT-hero-wireframe.md §6](docs/REPORT-hero-wireframe.md). Предыдущая
   сцена (воронка) держала гейт **до** `React.lazy` и телефон `three`
   не скачивал вовсе — если вес станет важнее фигуры, возвращать надо этот приём.

5. Если добавлялось медиа — перемерить. Бюджет владельца — **≤200 kB медиа выше
   сгиба**; фактически 16.9 kB на мобиле и 66.4 kB на десктопе (обложки ленты
   кейсов грузятся `eager` по требованию постановки, но с `fetchpriority="low"`,
   чтобы не отбирать канал у первого экрана). Всё остальное медиа — лениво.

## 5. Конвенции кода (обязательные)

- **Контент — в `src/data/*.ts`, разметка — в компонентах.** Правка текста не должна
  трогать `.tsx`. С контент-релиза v2 исключений нет: в компонентах не осталось
  ни одной пользовательской строки, включая подписи блоков и реквизиты футера.
- **Медиа: производные — в git, оригиналы — нет.** `public/media` коммитится,
  `site media/` (архив владельца) в `.gitignore`. Новый ассет: положить оригинал
  в архив → прописать в `scripts/optimize-media.mjs` → `npm run media` → описать
  в `src/data/media.ts` (интринсики из вывода скрипта, alt — осмысленный).
  Всё, что выводится из исходника кодом (`og.png`, `apple-touch-icon.png`),
  по-прежнему генерируется, а не коммитится.
- **Импорты только через alias `@/`.** Относительных `../` в `src/` быть не должно.
- ⚠️ **`three`, `@react-three/fiber` и `leva` импортируются ТОЛЬКО из сцен Hero,
  и каждая сцена подключена через `React.lazy`.** На этом держится весь бюджет
  первого экрана — 294.5 kB gzip лежат вне главного чанка. Действующий импортёр:
  [WireframeHeroCanvas.tsx](src/components/ui/WireframeHeroCanvas.tsx). Плюс
  `advance` в [useSceneLoop.ts](src/hooks/useSceneLoop.ts) — он тянется только
  из ленивых сцен. Неиспользуемые сцены (`ConversionFunnelCanvas.tsx`) тоже
  импортируют three, но из графа выпадают и в бандл не идут.

  Любой статический импорт three из компонента, который рендерится сразу,
  обнуляет разделение чанков **молча** — ни typecheck, ни браузер не заметят,
  увидите только по размеру `index-*.js`. Проверять после каждой правки сцены.

- ⚠️ **GLSL — шаблонными строками, `glslify` в проекте нет.** Шейдеры
  [wireframe.ts](src/shaders/wireframe.ts) перенесены из mattdesl/webgl-wireframes,
  где стоят `#pragma glslify: require`; они переписаны так, чтобы сборка
  не зависела ни от плагина, ни от Babel. Не заводить glslify обратно ради
  одной константы — инлайнить.
- Один компонент = одна секция, `export default`, без пропсов.
- Типы — `import type` (`isolatedModules: true`).
- Новые цвета/шрифты/easing — **токенами в `tailwind.config.js`**, не хардкодом в классах.
  Если значение нужно в чистом CSS — добавлять CSS-переменную в `src/index.css` и помнить,
  что источник правды всё равно один; расхождение `--accent` ↔ `colors.accent` — известная ловушка.
- Комментарии — только там, где приём неочевиден. Плотность держать как в окружающем коде (низкая).
- ⚠️ **Комментарии в `index.html` уезжают в прод как есть** — Vite их не вырезает,
  и любой посетитель читает их в исходном коде страницы. Держать короткими
  и техническими; разбор, даты, названия сторонних компаний и внутренние
  рассуждения — в `docs/`, со ссылкой из комментария. Проверено 2026-08-07:
  подробный комментарий про `sameAs` вынес имя посторонней организации
  в прод-разметку.
- UI-текст русский, идентификаторы английские.
- ⚠️ **Лимиты длины текста в этом репозитории — молчаливые.** `line-clamp` на
  заголовке карточки кейса и `break-words` в подписях метрик Hero не ломают
  вёрстку и не всплывают в typecheck — они просто режут строку (первый — по
  многоточию, второй — посреди слова), и на десктопе этого не видно. Лимиты
  записаны у самих полей (`title` в [src/types/index.ts](src/types/index.ts),
  `HERO_METRICS` в [src/data/heroMetrics.ts](src/data/heroMetrics.ts)) вместе
  со способом проверки. Меняя текст — сверяться с ними и перемерять на 320 px.
- ⚠️ **Новый шрифт — только после разбора `cmap`, а не по картинке на сайте
  производителя.** До 2026-08-08 в проекте стояли Clash Display и Space Grotesk,
  и ни в одном не было кириллицы: весь русский текст, то есть почти вся страница,
  рендерился системным `sans-serif`, хотя шрифты исправно грузились с двух CDN.
  Ровно на те же грабли едва не наступили с M PLUS 1 и Assistant — в них
  **0 кодпоинтов** в U+0400–U+04FF, у Assistant вдобавок нет `₽`, `№`, `→` и `◆`.
  Сейчас все три семейства покрытие имеют, проверено разбором `cmap`
  (`M PLUS Rounded 1c`, `IBM Plex Sans`, `JetBrains Mono`).
- ⚠️ **Курсива в наборе нет.** Ни у одного из трёх семейств нет курсивного
  начертания, поэтому `italic` в разметке быть не должно: браузер синтезирует
  наклон сам, и на крупном кегле это читается как дефект. Выделять цветом,
  кеглем или кавычками.

## 6. Границы скоупа — не «чинить» самовольно

Осознанные решения проекта, а не упущения:

- **Нет цен на странице** — вместо прайса блок «Смета до строки за 2 часа»
  (`estimate` в [src/data/process.ts](src/data/process.ts)). Не добавлять прайсинг.
- **Нет формы и бэкенда** — лид уходит в Telegram/почту. Не строить формы без задачи.
- **Мат в финальном оффере снят** по распоряжению владельца (2026-08-05) — теперь
  «Проекты начинаются с одного сообщения.» Не возвращать обратно.
- **Первый экран без картинок** — там типографика и процедурная 3D-сцена
  (wireframe на барицентрических координатах). Ни одного растрового ассета:
  геометрия и штрих считаются кодом. Медиа начинается с секции кейсов, всё лениво.
- ⚠️ **Композиция первого экрана: оффер СЛЕВА, фигура СПРАВА** (решение владельца
  2026-08-12, до этого фигура стояла слева и лежала под заголовком). Держится
  тремя связанными вещами, и трогать их можно только вместе:
  `WIRE.offsetXRatio` (знак), сторона маски `SCENE_MASK` (гаснет край, где фигуры
  нет) и колонка `max-w-[52rem]` в `HeroWireframe` (к ней привязаны `rem`-стопы
  маски). Разъедутся — текст ляжет на проволоку, и ни typecheck, ни браузер
  об этом не скажут. Способ проверки: правый край самой длинной строки Hero
  против первого непрозрачного стопа маски; разбор и числа —
  [REPORT-hero-wireframe.md §12](docs/REPORT-hero-wireframe.md).
- **Сцены Hero нет на 768–1023 px, и это не баг.** Колонка текста занимает там
  всю ширину контента, справа фигуре места нет. Планшет заодно не качает ленивый
  чанк 294 kB gzip. Вернуть фигуру в эту полосу можно только сузив колонку на md–lg.
- **Стартовая фигура — Sphere** (`WIRE.geometry`, распоряжение владельца
  2026-08-12). Это же значение по умолчанию у селектора в панели: второго места
  с дефолтом нет.
- ⚠️ **Панель параметров свёрнута по умолчанию, и разворачивать её обратно
  нельзя** (распоряжение владельца 2026-08-12), **а фигура вписана в полосу
  под панелью** (2026-08-13). Второе — не подобранные числа, а расчёт:
  `WIRE.panelReservedPx` (308 px, замеренный низ РАЗВЁРНУТОЙ панели) плюс
  `figureGapPx`, остаток высоты и есть место фигуры. Резерв держится всегда,
  даже когда панель свёрнута, иначе фигура прыгала бы в размере на каждое
  «развернуть».
  Что здесь легко сломать не заметив:
  - `offsetYRatio` больше НЕ существует — доля высоты промахивалась мимо
    панели, которая стоит в пикселях (на 1024×600 промах был 38 px);
  - размер ограничен не только шириной, но и свободной высотой, причём
    по угловому радиусу (камера перспективная) и по радиусу ТЕКУЩЕЙ фигуры
    из `WIRE.boundingRadius` — иначе TorusKnot вылезает под панель;
  - меняете вёрстку панели — перемеряйте `panelReservedPx`, связь молчаливая.
  Проверять по сетке вьюпортов, обязательно включая короткие (1024×600,
  1280×720): именно на них ломались все предыдущие подходы. Разбор и таблица
  зазоров — [REPORT-hero-wireframe.md §13–14](docs/REPORT-hero-wireframe.md).
- ⚠️ **Контурный текст (`text-hollow`) — не для длинных строк и не для крупного
  кегля.** Обводка 1 px при кегле 77 px даёт 1.3 % от роста буквы, а акцент
  и сплошным-то держит лишь 3.88:1: заголовок УТП так набранный читался как
  пустой блок (дефект закрыт 2026-08-13, бэклог §85). Приём остаётся живым там,
  где работает: цифры этапов в Process и `text-hollow-white` в ленте клиентов.
- **Рассказ кейса — в одном из двух форматов**, тройка Задача/Решение/Результат
  либо один абзац (`CaseNarrative`). Разные форматы у разных кейсов — решение
  владельца, а не недосмотр: у М.Видео тройка, у остальных трёх абзац.
  Прежние развёрнутые тексты удалены сознательно, не восстанавливать.
- **Палитра единая — «Leica Racing»** (зафиксирована 2026-08-11):
  `bg #050505`, `surface #111113`, `accent #D90429`, `accentMuted #8D081E`,
  `textMain #F5F5F7`. Форка у Hero больше нет, шов на стыке с Marquee закрыт.
  ⚠️ **ШЕСТЬ мест, править разом** — разбор в [data/palette.ts](src/data/palette.ts):
  сам `palette.ts`, `theme.extend.colors` в `tailwind.config.js`, `:root`
  в `src/index.css`, `theme-color` в `index.html`, константы
  в `scripts/generate-og.mjs`, и `public/favicon.svg`. Последние три при смене
  палитры 2026-08-11 нашлись только грепом по хексам — проверять
  `grep -rniE "<старый хекс>" .` по всему репозиторию, а не по `src/`.
- ⚠️ **Контраст акцента на фоне — 3.88:1**, то есть ниже AA (4.5) для обычного
  текста и годен только для крупного текста и UI-элементов. Замерено по WCAG;
  до смены палитры было 5.90. Практические следствия: подпись CTA набрана
  `textMain` (4.82:1), а не `bg` (было бы 3.88); `accentMuted` на фоне даёт
  **2.12:1** и текст им красить нельзя вообще — только декор.

## 8. RAG

Инструмент — из хаба: `D:\Code\platform\tooling\rag\rag.cmd` (на PATH как `rag`,
если развёрнут `platform Manager`; на этой машине шима на PATH **нет** — звать полным путём).

```bash
rag index --root .
```

```bash
rag query "marquee infinite scroll" --root . --top-k 5
```

Конфиг — [tools/rag.config.json](tools/rag.config.json). `maxFileBytes: 90000`
подобран так, чтобы `package-lock.json` (**119 КБ** после добавления three) не засорял
выдачу, а самые крупные документы в индекс попадали: `docs/SPEC-hero-truss.md` 71 КБ,
`docs/BACKLOG.md` 68 КБ. Здесь и в MEMORY значилось `65536` — при таком пороге спека
молча выпала бы из индекса; число исправлено 2026-08-06 по факту файла.
**Порог проверять при росте документов:** он молчаливый, выпавший файл ничем
не сигналит. Индекс `.rag/` самоигнорируется, в git не идёт.
Пересобирать после заметных правок исходников.
