# Бэклог — Vibe Engineering Landing

Результат аудита 2026-08-05. Шесть независимых линз (a11y, performance, SEO, код,
тулинг, дизайн-система), каждая находка проходила состязательную проверку по коду:
72 находки → 63 подтверждено, 9 опровергнуто. Severity ниже — **после** корректировок
верификации, а не исходные оценки линз.

Часть пунктов дополнительно перемерена вручную в браузере на dev-сборке —
такие помечены **`[замерено]`** и имеют конкретные числа.

> Легенда effort: **S** — до часа, **M** — полдня, **L** — больше дня.
> Пункты с ❓ требуют решения владельца продукта, а не разработчика.

## P0 — брать первым

Дёшево, заметно, ничего не ломает.

### 1. Нет обработки `prefers-reduced-motion` `[замерено]` · high · M

**Замер:** 0 правил `prefers-reduced-motion` из 191 CSS-правила страницы; в момент
загрузки крутятся 3 бесконечные анимации (`gridShift`, `marquee`, `pulseDot`) плюс
`scroll-behavior: smooth` и 32 инстанса Framer Motion.

Пользователь с вестибулярными нарушениями получает движение, которое системной
настройкой отключить нельзя. Главный раздражитель — `marquee` 28 s с текстом 36–60 px
и smooth scroll; `gridShift` вносит мало (линии `rgba(136,136,136,0.03)` почти не видны),
reveal'ы играют по разу (`viewport={{ once: true }}`).

**Fix — обе половины обязательны:**

1. В [src/index.css](../src/index.css) — блок под `@layer utilities` (не голым правилом:
   утилиты Tailwind идут после пользовательских правил и перебьют его):
   `@media (prefers-reduced-motion: reduce)` → `animation-duration: .01ms !important`,
   `animation-iteration-count: 1 !important`, `transition-duration: .01ms !important`,
   `html { scroll-behavior: auto }`.
2. В [src/main.tsx](../src/main.tsx) обернуть `<App/>` в `<MotionConfig reducedMotion="user">`.
   **CSS сам по себе Framer Motion не гасит** — тот анимирует inline-стили через rAF/WAAPI.

### 2. `RevealText` обрезает выносные элементы букв `[замерено]` · high · S

**Замер** на слове «порталы.» в h1 (Clash Display 600, 72 px, `leading-[0.92]`):
высота маски **66.23 px**, нижняя граница ink-бокса глифов **70.12 px** →
**3.88 px описания буквы «р» срезано** `overflow-hidden`.

Затронуто везде, где `RevealText` стоит внутри заголовка с `leading < 1`:
[Hero.tsx:27](../src/components/Hero.tsx:27) `leading-[0.92]`,
[USP.tsx:35](../src/components/USP.tsx:35) `leading-[0.9]`,
[Contact.tsx:59](../src/components/Contact.tsx:59) `leading-[0.95]`, плюс заголовки
секций с `md:text-6xl` (line-height: 1) в Cases/Process/Team.

**Fix:** расширить окно клипа **симметрично** — при `leading < 1` срезается и верх
(буквы «й», «ё» — «Давай билдить», [Contact.tsx:65](../src/components/Contact.tsx:65)):
`pt-[0.15em] -mt-[0.15em] pb-[0.2em] -mb-[0.2em]` на маске **и одновременно** увеличить
стартовый сдвиг с `y: "110%"` — иначе текст будет виден в исходном положении.
Обязательна визуальная приёмка: точный запас зависит от метрик Clash Display.

### 3. `npm run lint` гарантированно падает · medium · S

[package.json:11](../package.json:11) объявляет `"lint": "eslint ."`, при этом eslint
нет ни в `dependencies`, ни в `devDependencies`, ни в `node_modules`, ни в
`package-lock.json`; конфига в репозитории тоже нет. Проверено запуском:
`'eslint' is not recognized`.

Прод не страдает — гейт `tsc --noEmit` в `build` работает. Страдает достоверность:
README и `package.json` обещают проверку, которой нет.

**Fix:** либо поставить eslint 9 с flat config (`eslint.config.js` +
`typescript-eslint` + `eslint-plugin-react-hooks`), либо убрать скрипт.
Половинчатого варианта нет.

### 4. Нет favicon · medium · S

`/favicon.ico` отдаёт 404, каталога `public/` не существует. Google показывает favicon
рядом со сниппетом в мобильной выдаче — там будет заглушка.

**Fix:** `public/favicon.svg` (монограмма VE акцентом на `#0D0D0D`) +
`<link rel="icon" type="image/svg+xml">` + `apple-touch-icon.png` 180×180.
Веб-манифест для лендинга без PWA-сценария не нужен.

## P1 — шеринг и индексация

### 5. Нет `og:image` · high · M ❓

Ссылка на сайт разворачивается в Telegram, Slack, VK и LinkedIn без картинки.
Это прямое следствие политики «в репозитории нет ни одного графического ассета»
(см. [ARCHITECTURE.md](ARCHITECTURE.md) §10) — то есть решение нужно принять, а не просто закодить.

**Fix:** сгенерировать OG-карточку 1200×630 в языке бренда (чёрный фон, Clash Display,
акцент), положить в `public/`, добавить `og:image`, `og:image:width/height`, `og:image:alt`.

### 6. Соцмета неполная · low · S

Нет `og:site_name`, `og:locale=ru_RU`, `og:url`, `twitter:card`.
`twitter:card="summary_large_image"` **бессмысленна до закрытия п.5** — без картинки
крупная карточка деградирует в ту же текстовую строку. Порядок: сначала п.5, потом
одним коммитом весь блок.

### 7. Нет `canonical` и `og:url` · medium · S ❓

Прод-домен нигде в репозитории не объявлен: есть только почта `hq@vibeengineering.ru`
и отсутствующий deploy-конфиг. `canonical` на несуществующий адрес хуже, чем его отсутствие.
**Сначала подтвердить хост (с `www` или без), потом добавлять.**

### 8. CSR без пререндера: в HTML отдаётся пустой `#root` · high · M

[index.html:40](../index.html:40) — `<div id="root"></div>`; в собранном
`dist/index.html` то же самое. Ни SSR, ни пререндера в зависимостях нет.

Тезис «соцботы не видят ни одного слова» **неверен** — `og:title`/`og:description`
лежат в статическом `<head>`, текстовое превью формируется. Реальный ущерб:
(а) Яндекс рендерит JS ограниченно и с задержкой, (б) при сбое загрузки бандла
(корпоративный прокси, блокировка домена) страница остаётся навсегда пустой —
ни одного контакта.

**Fix — дешёвый вариант предпочтительнее:** положить статический фолбэк прямо внутрь
`<div id="root">` (h1, оффер-абзац, 4 заголовка кейсов, контакты).
`ReactDOM.createRoot(...).render()` в [main.tsx:6](../src/main.tsx:6) полностью замещает
детей контейнера — дублей пользователь не увидит.
Тянуть `vite-prerender-plugin`/`react-snap` в проект без тестов и CI — избыточно.

### 9. Нет JSON-LD `Organization` · low · S

Дешёвая гигиена, не рычаг ранжирования. Требует того же неподтверждённого домена,
что и п.7. В `sameAs` нельзя класть непроверенные профили: `github.com/vibeengineering`
взят из [Contact.tsx:21](../src/components/Contact.tsx:21) и в репозитории не подтверждён.

### 10. Нет `robots.txt` / `sitemap.xml` · low · S

Отсутствие `robots.txt` трактуется краулерами как allow-all; `sitemap.xml` с единственным
`<url>` не даёт ничего сверх главной. Ценность — формальная галочка при добавлении сайта
в Яндекс.Вебмастер / GSC. Делать вместе с п.4 (тот же каталог `public/`).

### 11. `<title>` полностью на английском · low · S

При `lang="ru"` и русскоязычной аудитории. Описание при этом **в порядке** — вопреки
первичной находке, [index.html:10](../index.html:10) перечисляет услуги явно («MVP, боты,
AI-интеграции. Спринты от 7 дней»); не хватает только гео.

**Fix:** переписать `title` (бренд + русская услуга), дописать «Москва» в `description`.
Переписывать описание целиком не надо.

## P2 — производительность

### 12. LCP полностью завязан на выполнение JS · high · M

Следствие п.8, усиленное `RevealText`: h1 в Hero собран из 6 `RevealText`, каждый
стартует с `y: 110%` внутри `overflow-hidden`, то есть визуально пуст;
[Hero.tsx:14](../src/components/Hero.tsx:14) и `:46` стартуют с `opacity: 0`
(элементы с `opacity: 0` Chrome вообще исключает из кандидатов LCP).

⚠️ Ранняя редакция [ARCHITECTURE.md](ARCHITECTURE.md) утверждала, что Hero использует
`animate`, а не `whileInView` — это верно только для микро-лейбла и абзаца; **сам h1 идёт
через `RevealText`/`whileInView`**. Документ исправлен.

**Fix:** для above-the-fold рендерить h1 без скрывающего `initial` (или сделать reveal
чистым CSS `@keyframes` со стартом по загрузке документа); `whileInView` оставить
секциям ниже сгиба. Реальный выигрыш по LCP даст только п.8.

### 13. Шрифты: цепочка HTML → CSS → woff2 с двух сторонних origin `[замерено]` · medium · M

**Замер:** 2 внешних запроса (`api.fontshare.com`, `fonts.googleapis.com`), оба —
render-blocking `<link rel="stylesheet">` в `<head>`. Объявлено **31** `@font-face`,
реально загружается **6** начертаний в 3 семействах.

Из этого следует, что **лишние веса в запросе (300/700) байт не стоят** — браузер качает
woff2 только для реально применённых начертаний. Первичная находка про «лишние сетевые
запросы» опровергнута.

Реальная цена — лишний RTT перед стартом загрузки woff2 и конкуренция за соединения
с 270 КБ JS. `preconnect` уже стоит ([index.html:22-24](../index.html:22)), `preload as=style`
для fontshare — тоже, так что худший сценарий частично закрыт.

**Fix:** self-host шрифтов в `public/fonts/` + `<link rel="preload" as="font" crossorigin>`.
Мерить по FCP/LCP до и после, а не по числу запросов.

### 14. Нет метрически совместимого fallback → CLS на главном заголовке · medium · M

`display=swap` + заголовок в `13vw`: подмена системного шрифта на Clash Display
двигает крупнейший блок страницы.

**Fix:** self-host + `preload` (чтобы загрузка началась до выполнения бандла) +
fallback-`@font-face` с `size-adjust`/`ascent-override`.
⚠️ `font-display: optional` **без preload сделает хуже** — шрифт не успеет к первому
paint и останется fallback навсегда.

### 15. Полный `framer-motion` ради простых reveal'ов · medium · M

~34 КБ gzip против ~18 КБ у связки `LazyMotion` + `domAnimation` + `m`.
Выигрыш реален, но вдвое меньше, чем показалось первичной находке.

⚠️ Замена `motion[as]` на `switch` в [RevealText.tsx:29](../src/components/ui/RevealText.tsx:29)
**сама по себе ничего не экономит** — полный набор фич тянется самим импортом `motion`,
это дизайн пакета. Нужен именно переход на `m` + `LazyMotion`.

### 16. `.bg-grid` перерисовывает вьюпорт каждый кадр · low · S

[index.css:62](../src/index.css:62) анимирует `background-position` на `fixed`-слое
во весь экран, бесконечно. Содержимое paint'а тривиально (два `linear-gradient`,
линии 1 px, alpha 0.03) — проблема в постоянстве, а не в стоимости кадра.

**Fix:** внутренний div, увеличенный на размер тайла, и `transform: translate3d`
вместо `background-position`. `will-change: transform` на всегда-анимируемом
полноэкранном слое стоит GPU-памяти — добавлять осознанно.

### 17. `vite.config.ts` без секции `build` · low · S

Нет `manualChunks` — весь код в одном бандле. Кэширование vendor-части при правках
контента не работает.

⚠️ `target: 'es2020'` и `cssCodeSplit: true` добавлять **не нужно** — это уже дефолты
Vite 5. Единственная осмысленная правка — vendor-чанк.

## P3 — доступность

### 18. Бегущую строку нельзя остановить с клавиатуры и с тача · high · M

[Marquee.tsx:12](../src/components/Marquee.tsx:12) — пауза только по `group-hover`.
Движение длится дольше 5 секунд и не имеет доступного механизма остановки — WCAG 2.2.2.

**Fix:** кнопка «пауза/воспроизведение» с `aria-pressed`, **вынесенная из бегущего трека**
(внутри она уедет вместе с ним). Вариант «продублировать на `focus-within`» — недостаточная
полумера: тач-пользователям она не помогает.

### 19. Тач-цели меньше минимума `[замерено]` · medium · S

**Замер** реальных боксов: пункты меню `work` 36×16, `team` 36×16, `process` 64×16,
`contact` 64×16; логотип `VE` 31×24; почта в футере 335×**17**.
Минимум WCAG 2.5.8 (AA) — 24×24 CSS-px; по высоте не проходит ни один из перечисленных.

**Fix:** вертикальные паддинги на ссылки (`py-2` даёт 32 px высоты) — визуально
ничего не сдвинет, так как шапка и футер уже flex-выровнены.

### 20. `mix-blend-difference` на шапке: контраст позиционный · medium · M

Над доминирующим `#0D0D0D` difference даёт ≈`#E7E7E3`, контраст ~15:1 — всё в порядке.
Провал возникает **точечно**, когда под шапкой светлый или акцентный контент — и это
происходит на первом экране (оранжевый CTA, крупный h1).

**Fix:** отслеживать пересечение шапки с акцентными блоками и переключать её
в обычный режим с явным фоном, либо дать шапке полупрозрачную подложку при `scrolled`.

### 21. Нет фирменных focus-стилей `[замерено]` · medium · S

**Замер:** UA-кольцо на месте — при реальном Tab на пункте меню computed style даёт
`outline: auto 1px rgb(229,151,0)`, `:focus-visible` матчится.
Tailwind preflight `outline` не обнуляет, поэтому **формально SC 2.4.7 не провален** —
первичная формулировка «блокер клавиатурной навигации» неверна.

Проблема в другом: кольцо не спроектировано и находится внутри
`mix-blend-difference`-шапки, где его цвет инвертируется непредсказуемо.

**Fix:** явные `focus-visible:` утилиты в фирменном акценте
(`focus-visible:outline focus-visible:outline-2 focus-visible:outline-accent
focus-visible:outline-offset-2`) на всех ссылках и CTA.

### 22. «Готовы?» — не заголовок, `<footer>` внутри `<main>` · medium · S

[Contact.tsx:31](../src/components/Contact.tsx:31): крупнейший визуальный заголовок
секции размечен `<p>`, а единственный `h2` секции — финальный слоган.
Плюс `<footer>` вложен в `<main>` вместо того, чтобы быть на уровне страницы.

**Fix:** «Готовы?» → `h2` секции; слоган опустить до `h3` либо оставить `<p>`.
`<footer>` вынести из `<main>` в [App.tsx](../src/App.tsx:15).

### 23. Ниже `md` навигации нет вовсе · medium · M

[Nav.tsx:35](../src/components/Nav.tsx:35) — `hidden … md:flex`. Бургера нет.
Контент не становится недостижимым (CTA `#contact` есть в Hero, остальное — скроллом),
но быстрые переходы к `#work`/`#process`/`#team` на мобильном теряются, и единственная
кнопка в мобильной шапке уводит на внешний `t.me`.

⚠️ «Просто показать 4 ссылки в строку» на 375 px не поместится вместе с логотипом
и кнопкой Telegram в одном flex-ряду — нужен либо бургер, либо перенос.

### 24. Английские вставки не размечены `lang="en"` · low · S

«Hardware is dead. We write code now.» ([Hero.tsx:21](../src/components/Hero.tsx:21)),
`◆ Selected Work`, `◆ Founders`, роли в `team.ts`. Синтезатор речи читает их русской
фонетикой. Английских узлов ~10 — объём небольшой, правка механическая.

### 25. Клон списка в marquee читается скринридером дважды · low · S

Дублирование в [Marquee.tsx:5](../src/components/Marquee.tsx:5) нужно для бесшовной
петли. Это избыточность озвучки, а не барьер.

**Fix (минимальный):** `aria-hidden` на весь трек + визуально скрытый список имён
рядом. Расщеплять рендер на два трека не обязательно.

### 26. Скроллбар принудительно скрыт · low · S

[index.css:39-48](../src/index.css:39). Формально WCAG не нарушен, но пользователь
теряет индикатор позиции и возможность тащить полосу мышью на странице высотой ~7000 px.

**Fix, сохраняющий дизайн-намерение:** не убирать блок, а заменить на
`scrollbar-width: thin` + `scrollbar-color` под тёмную тему.

### 27. Контурный текст `color: transparent` · low · M

`.text-hollow-white` — обводка `rgba(244,244,240,0.35)`, контраст ≈3.0:1.
Весь текст этого класса — крупный (порог AA для крупного = 3:1), то есть это **граница,
а не провал**. Аргумент «обводка читается хуже заливки» верен, но WCAG его не измеряет.

**Fix:** поднять альфу обводки до ~0.5 в marquee. Приоритет низкий.

## Опровергнутые находки

Зафиксированы, чтобы их не «нашли» заново. Каждая проверена по коду или замером.

| Находка | Почему неверна |
|---------|----------------|
| Переполнение строк на 320 px | **Замерено:** при `clientWidth = 320` ни один элемент не выходит за вьюпорт (`unclippedCount: 0`), ink-overflow у меток Contact = 0, горизонтального скролла нет (`window.scrollX` остаётся 0). Часть про футер неверна отдельно: ниже `md` он `flex-direction: column` |
| `.gitignore` не закрывает `.env` | Это стоковый шаблон Vite, где `.env` предназначен для коммита, а секреты идут в `.env.local` (покрыт `*.local`). Любая `VITE_*`-переменная по построению попадает в клиентский бандл и секретом быть не может |
| Имя `process` в `data/process.ts` затеняет глобаль Node | Импорт создаёт модульную привязку только внутри файла. Предложенный фикс `"types": ["vite/client"]` **сломал бы сборку**: tsconfig включает `vite.config.ts`, который использует `node:path` и `__dirname` |
| Загружаются лишние начертания 300/700 | **Замерено:** объявлен 31 `@font-face`, загружено 6. Браузер качает woff2 только для применённых начертаний; неиспользуемые стоят десятки байт в CSS |
| `transition-all` на padding шапки — layout-анимация | Шапка `position: fixed` (вне потока), поддерево из 4 узлов, переход отрабатывает один раз при пересечении порога 24 px. Предложенный `scale-y-[0.85]` сжал бы логотип — фикс хуже проблемы |
| Типы не фиксируют число метрик | Во всех данных ровно по 3 элемента. Профилактическое ужесточение, а не дефект. Реально хрупкое место другое — вёрстка Team на 2 карточки (п.34) |
| Нет `scroll-padding-top` под фиксированной шапкой | Секции имеют `py-24`/`md:py-40` — заголовок не попадает под шапку высотой 56–72 px |
| Marquee: hover-переход обводки перерисовывает большой слой на ходу | Наведение сначала ставит ленту на паузу (`group-hover:[animation-play-state:paused]`), переход отрабатывает на неподвижном слое |
| vw-типографика без `clamp()` вызывает CLS | Пересчёт происходит только при resize окна; у пользователя с фиксированным вьюпортом не проявляется |
